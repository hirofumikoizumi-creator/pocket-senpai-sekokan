ポケット先輩（施工管理）

建設・土木の施工管理を学ぶ新人・若手向けの教育・学習支援アプリです。

安全管理、品質管理、工程管理、施工計画、関係者調整など、現場でつまずきやすいポイントを、先輩相談AIチャット、チェックリスト、会話例、ミニクイズで確認できます。

主な機能

  • 先輩相談AIチャット: 困りごとの整理と確認観点の洗い出しをサポート
  • 業務別マニュアル: 安全、品質、工程、施工計画、関係者調整の基本を確認
  • 現場トーク集: 上長、職長、発注者への報告・確認表現を練習
  • チェックリスト: 朝礼、KY、写真管理、工程調整の抜け漏れを確認
  • ミニ学習クイズ: 施工管理の基本を短時間で復習

注意事項

本アプリは教育・学習支援を目的とした参考情報アプリです。法令適合、構造安全、施工可否、労働安全、災害・事故対応などの判断を代替するものではありません。実務では法令、設計図書、仕様書、元請・発注者・所属会社のルール、有資格者・監督者の指示に従ってください。
